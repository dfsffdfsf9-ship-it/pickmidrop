## 🚀 2. Покрокова інструкція запуску проєкту

### Крок 1. Перевірка та встановлення Node.js
Переконайтеся, що встановлено Node.js актуальної LTS версії:
```bash
node -v   # Має бути v20.x (наприклад, v20.18.0)
npm -v    # Має бути v10.x
```
> *Порада:* Якщо ви використовуєте NVM (Node Version Manager):
> ```bash
> nvm use
> ```

### Крок 2. Клонування репозиторію та перехід у директорію
```bash
git clone https://github.com/your-org/pickmidrop.git
cd pickmidrop
```

### Крок 3. Налаштування конфігурації без секретів
Скопіюйте шаблон змінних оточення у локальний файл `.env`:
```bash
# Windows PowerShell:
Copy-Item .env.example .env

# Linux / macOS / Bash:
cp .env.example .env
```
У файлі `.env.example` містяться виключно безпечні плейсхолдери та мокові налаштування:
- `STEAM_APP_ID=480` (стандартний тестовий ідентифікатор Spacewar)
- `VITE_ENABLE_MOCK_STEAM=true` (дозволяє запускати інтерфейс без активного клієнта Steam)

### Крок 4. Встановлення залежностей
```bash
npm install
```
*(Для детермінованого встановлення на CI/CD серверах використовуйте `npm ci`)*.

### Крок 5. Запуск у режимі розробки
```bash
npm run dev
```
Після виконання консоль виведе посилання на локальний сервер:
```
  VITE v5.2.11  ready in 180 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```
Відкрийте `http://localhost:5173/` у будь-якому сучасному веб-переглядачі.

### Крок 6. Збірка для продакшну / Netlify / Steam
```bash
npm run build
```
Готовий статичний бандл генерується у директорії [`dist/`](file:///c:/Users/sladk/Downloads/PickmiDrop/dist/).

## 🔒 3. Аудит безпеки: відсутність секретів у репозиторії

Усі конфігураційні файли репозиторію перевірено на відповідність стандартам безпеки:

1. **Відсутність реальних API-ключів та токенів у конфігах**:
   - Файл `.env` **не закоммічений** у репозиторій.
   - Файл [`.env.example`](file:///c:/Users/sladk/Downloads/PickmiDrop/.env.example) містить лише безпечні значення-заглушки:
     ```env
     STEAM_APP_ID=480
     STEAM_API_KEY=your_steam_web_api_key_here
     TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
     TELEGRAM_CHANNEL_ID=@pickmidrop_news
     VITE_ENABLE_MOCK_STEAM=true
     ```
2. **Розширені правила [`.gitignore`](file:///c:/Users/sladk/Downloads/PickmiDrop/.gitignore)**:
   - Заблоковано будь-які варіації `.env` (`.env.local`, `.env.*.local`).
   - Заблоковано сертифікати та приватні ключі (`*.pem`, `*.key`, `*.cert`, `*.pfx`, `*.p12`).
   - Заблоковано SSH-ключі (`id_rsa`, `id_ed25519`) та облікові файли (`credentials.json`, `client_secret*.json`).
3. **Захист від випадкового витоку**:
   - Усі секрети команди (Steam Web API Key, токен Telegram-бота) зберігаються виключно в захищеному сховищі команди (1Password / Vault) і передаються розробникам персонально для локального `.env`.
